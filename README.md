# GymFlow — complete editable browser prototype

## Run on Windows

1. Extract this ZIP into `C:\Users\Dawid\Desktop\GymFlow Codex`.
   `START.bat`, `package.json`, and the `dist` folder should be directly inside that folder.
2. Install Node.js LTS from https://nodejs.org if Node is not already installed.
3. Double-click `START.bat`. Your browser opens http://127.0.0.1:5173.
4. Keep the terminal window open while using the app. Press Ctrl+C to stop it.

Alternatively, open a terminal in this folder and run `npm start`.
No npm install or build step is required. Do not open index.html directly: JavaScript modules require a web server.

## Continue development in Codex or Claude

Open this entire folder as your project. All app source is editable inside `dist/`:

- `index.html`, `style.css`: interface and responsive styling.
- `app.js`: application state, interactions and workout flow.
- `map.js`, `equipment-models.js`: interactive Three.js scene and detailed procedural 3D equipment.
- `gyms.js`, `gym-routing.js`: gym layouts, floors and route calculation.
- `data.js`: equipment descriptions and workout data.
- `workout-editor.js`: custom workout editor.
- `i18n.js`: English and Polish translations.
- `camera-navigation.js`: WASD camera movement.
- `vendor/`: bundled Three.js modules and their license.

Save a source file and refresh the browser to see changes. The project uses plain HTML, CSS and JavaScript with Three.js; it does not need React or Vite. The detailed 3D models are generated by JavaScript, so there are no separate Blender/GLB model files.

## Included features

Studio 01 with 30 stations; Atlas Club with 24 stations across two selectable floors; clickable equipment instructions; workout routes; preset and custom plans; per-exercise sets, repetitions, rest, target weight and notes; English/Polish toggle; dark/light mode; WASD camera navigation.

## Prototype scope

No accounts, payment processing or backend. Android/iOS packaging has not been implemented. Plans and progress are saved in the current browser's local storage, separately for each gym. Data from the hosted website will not automatically appear on localhost because these are different browser origins. Clearing browser data removes local plans.

The gym layouts are examples. Three.js is bundled locally; Google Fonts may load from the internet, with system fonts as fallback. The local server listens only on your own computer. For hosting, publish the contents of `dist/` to a static web host.
